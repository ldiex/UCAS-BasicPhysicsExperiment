3.  **实验原理**

**3.1 弦上驻波实验**

**1、弦上驻波产生的原理:**

当弦长$L$与波长$\lambda$之间的关系可以使得前进波和许多反射波都有相同的相位时，弦线上的各点都做各自恒定的简谐振动。则弦线上有些点振动的振幅最大，称为波腹；而另外有些点的振幅为零，称为波节，这就形成了**驻波**现象.

**2、基频与倍频的概念：**

考虑两列振幅相等、频率相同又有固定相位差且传播方向相反的简谐波：

$$u_{1}(x,t) = Acos(kx - \omega t - \varphi)$$

$$u_{2}(x,t) = Acos(kx + \omega t)$$

叠加后有：

$$u(x,t) = 2Acos(kx - \frac{\varphi}{2})cos(\omega t + \frac{\varphi}{2})$$

带入边界条件，即令$u(x,t)$在$x$在弦的两端都为0，则可以解出$\varphi = \pi$，说明$u_{1}$和$u_{2}$有着固定的相位差$\pi$。

代入上式得：

$kl = n\pi$ 或 $\lambda = \frac{2l}{n}$ $(n = 1,2,3\ldots\ldots)$

进一步有：

$$f_{n} = \frac{\omega}{2\pi} = \frac{kv}{2\pi} = n\frac{v}{2l}$$

其中$f_{1}$称为基频，是振动中的最低频率，也是仅产生一个波腹时弦线的振动频率；

$f_{n}$称为$n$倍频，是产生$n$个波腹时弦线的振动频率。

**3、波在弦上的传播速度：**

根据波动理论，设弦线承受的张力为$T$，弦线的线密度为$\mu$，波在传播方向上的位置坐标为$x$，振动位移为$y$，取一段微元分析，则可得到其对应的微分方程：

$$\frac{\partial^{2}y}{\partial t^{2}} = \frac{T}{\mu}\frac{\partial^{2}y}{\partial x^{2}}$$

对比一般形式的波动方程：

$$\frac{\partial^{2}y}{\partial t^{2}} = v^{2}\frac{\partial^{2}y}{\partial x^{2}}$$

由此就可以得到波速的**理论值**：

$$v = \sqrt{\frac{T}{\mu}}$$

同时根据测出的频率，可以计算得到波速的**测量值**：

$$v = f\lambda$$

实验中可以通过对比理论值与测量值，分析其中的区别及其原因。

**4、影响弦上驻波基频的因素：**

根据波速的理论值$v = \sqrt{\frac{T}{\mu}}$和测量值$v = f\lambda$，我们可以得到频率的表达式：

$$f = \frac{1}{\lambda}\sqrt{\frac{T}{\mu}}$$

其中$\lambda$为波长，$T$为张力，$\mu$为弦线的线密度。对上式两边同取对数，有：

$$\log f = \frac{1}{2}logT - \frac{1}{2}log\mu - log\lambda$$

上式中有一个因变量变量频率$f$，和四个自变量张力$T$，线密度$\mu$和波长$\lambda$。我们使用控制变量法，固定自变量中的两个，分析另一个自变量和因变量f之间的关系。又由上式我们可以得知，不同自变量和因变量的对数值都是线性关系，所以我们可以用作图软件，通过作图法来对其进行线性拟合，从而得出不同自变量对于因变量频率$f$的影响，从而考察影响弦上驻波基频的各种因素。

**3.2 声速测量实验**

**1、驻波法测定声速：**

驻波法又称为共振干涉法，通过调节两个探头之间的距离，就可以使发射波和接受波形成稳定的驻波。此时，两换能器之间的距离恰好等于其声波半波长的整数倍，在声驻波中，波腹处声压最小，波节处声压最大。接收换能器的反射界面处为波节，声压效果最大。所以，可以从使用接收示波器的$Y - T$模式显示，当接收到的振幅达到最大值时，就可以判断其形成了驻波。

两探头之间的距离是通过鼓轮来调节的。则转动鼓轮，记下出现示波器上最大振幅数值时标尺上的刻度，相邻两次最大值对应的刻度值之差即为半波长$\frac{\lambda}{2}$

由于声波的频率$f$是一个确定的数值，所以测出波长后，可以用公式：$v = \lambda \times f$
来计算超声波的传播速度。

**2、位相法测定声速：**

相位法又称为行波法，是将发射波和接受波同时输入示波器，转换示波器的模式为$X - Y$由于两束波频率相同，且相位不同，所以在示波器$X - Y$模式下，可以根据其相位差的不同，出现不同的李萨茹图形。

由上图我们可以知道，比较两信号的相位差，相位差从$\pi$变为$2\pi$时对应半波长。所以我们在实验时，可以通过改变发生器和接收器的距离，观察相位变化，从而得出波长$\lambda$。再通过和驻波法测声速时类似的方法，得到对应的波速$v$。

**3、测定弦线上横波的传播速度：**

（1）用标准千克砝码对电子天平进行调零，而后测出钩码的质量$m$；

（2）将两个琴码分别放在150mm和650mm处，用于控制弦线的有效长度为500(mm)

（3）将钩码置于第二个挂点位置，调节仪器左下角的旋钮并观察气泡至水平状态；

（4）调整信号发生器的输出频率（微调按钮似乎有问题，只能粗调），使得弦线上形成一个稳定波腹，记录此时弦线的振动频率$f_{1}$，即基频；

（5）调整信号发生器的输出频率，使得弦线上分别形成两个和三个稳定波腹，记录对应时刻弦线的振动频率$f_{2}$和$f_{3}$，即二倍频和三倍频，并拍照作记录；

（6）再将钩码分别置于第三个和第四个挂点位置，并重复前面（3）\~（5）的步骤，测出相应的数据；

（7）根据公式$v = \sqrt{\frac{T}{\mu}}$和$T = \frac{1}{2}nmg$（$n$表示钩码在第$n$格）计算相应波速的理论值；

（8）根据公式$v = f\lambda$和测量的数据，计算相应波速的测量值，其中$f$取频率的平均值；

（9）对比分析理论值与测量值的区别，并计算相对误差。

**4、探究频率和有效长度的关系：**

（1）固定钩码在第二个格子，即固定$T = \frac{1}{2}*2mg = mg$，并调节仪器至水平；

（2）移动两个琴码，使得其间的有效长度$L$分别为640mm，480mm，320mm，240mm，160mm；

（3）调整信号发生器的输出频率，使得弦线上形成一个稳定波腹，记录弦线在不同有效长度时对应的振动频率$f_{1}$，即基频；

（4）根据测得的数据计算相应的波速$v$，从而分析得出频率$f$和有效长度$L$的关系。

**5、探究频率与弦线所受张力的关系：**

（1）移动琴码，并固定弦线的有效长度为400mm；

（2）分别将钩码放在不同位点处，调节仪器至水平，并计算对应的弦线张力$T$；

（3）调整信号发生器的输出频率，使得弦线上形成一个稳定波腹，记录弦线在承受不同张力时对应的振动频率$f_{1}$，即基频；

（4）利用作图软件，绘制出$logf - \log T$曲线，并进行线性拟合，对比分析斜率和截距的拟合值与理论值。

**6、探究频率与线密度的关系：**

（1）共享同组人员不同号弦线的线密度$\mu$和上一实验中，记录钩码位于第3格时候的振动频率f~1~（基频）；

6.  **实验总结与思考**

**6.1 总结**

**6.1.1 弦线上驻波测量**

1\. 实验中所用的弦显然不同与理论计算中
"理想弦"，推导过程中使用的近似公式在实际情况中未必可用，现实中可能存在色散效应和其他非线性效应的影响，因此导致实测值和理论值仍有误差

2\.
由于实验环境的不稳定，可能导致测量的误差。比如在弦线已经共振时，随意按压桌子可能导致共振消失。且信号源输出频率也不是非常稳定。

3\.
改变张力后，需要对气泡调平。但发生振动时，水平可能被打破，导致误差产生。

**6.2.2 介质中声速测量**

1\. 实验数据处理时，采用逐差法，对数据的利用程度高，实验整体误差较小。

2\.
相位法测量的结果要比驻波法更为精确，其原因是驻波法测量时，波峰或波谷的位置用肉眼难以准确辨别，而相位法的李萨如图形较容易观察准确。

**6.2 思考题**

1\. 调节振动源上的振动频率和振幅大小后对弦线振动会产生什么影响？

调节振动源的振幅频率可以改变弦线的振动频率，如果振动源的振动频率是弦线基频的整数倍，则弦线发生共振，形成稳定驻波。调节振动源的振幅大小会使弦线的振动更加明显，振动声音也更大，便于观察判断驻波的形成。

2\. 如何来确定弦线上的波节点位置？

当弦线上产生稳定驻波时，可以通过观测振幅较小或无振幅的点，即为波节。但有时候波节十分不明显，此时可以根据弦线长度与波长计算波节位置。

3\.
在弦线上出现驻波的条件是什么？在实验中为什么要把弦线的振动调到驻波现在最稳定、最显著的状态？

出现驻波的条件是振动源的频率是弦线基频的整数倍或者弦线的有效长度是半波长的整数倍，即：

$$L = n\frac{\lambda}{2}，n = 1,2,3\ldots\ldots$$

把弦线的振动调到驻波现在最稳定、最显著的状态可以观察到最明显的驻波现象，使得误差减小，计算结果更加精确。

4\.
在弹奏弦线乐器时，发出声音的音调与弦线的长度、粗细、松紧程度有什么关系？为什么？

由公式：

$$f = \frac{1}{\lambda}\sqrt{\frac{T}{\mu}} = \frac{2}{\lambda}\sqrt{\frac{T}{\pi\rho d^{2}}}$$

可得：弦的有效长度越短、直径越细、绷得越紧，发出声音的音调越高。

5\. 若样品弦线与装置上的弦线直径略有差别，请判断是否需要修正，如何进行？

需要修正。可以使用螺旋测微器测量装置上的紧绷状态下的弦线的直径，根据比例推算若弦线样本的直径与其相等的话，长度会是多少。当然根据本次实验经验，弦线与样品可能材质也存在不同。

6\.
对于某一共振频率，增大或减少频率的调节过程中，振幅最大的频率位置往往不同，如何解释这一现象？

可能是仪器本身的问题，信号发生器的频率输出经常会发生突变，很难得到一个准确的读数。

7.  **反思**

1.实验前务必要预习，尤其是透彻理解实验理论与原理

如果不预习，在操作时难免出现错误，甚至会导致一些严重后果，比如损坏仪器或伤人。而且对实验不熟悉不利于我们的操作与思考。

2.认真对待误差分析

做实验时，要格外留意会存在哪些带来误差的地方，并且反思这样的误差是否是可以采用别的方法，从而尽可能的减少影响。

3.多请教老师对于快速掌握实验技巧很有帮助

每个人都有可能会在操作中遇到更特殊的问题，甚至有可能是仪器本身的问题，这时候及时请教老师是最好的选择，既能解决实验中的问题，还能在解决问题时加深对实验本身的理解。
