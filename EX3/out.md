3.  **实验原理**

**弦上驻波实验**

**1．驻波产生原理**

将一根弦线的两端 A，B 固定，弦线以一定的张力绷紧。这时，如果在 A，B
端点之间有策动源使弦线在A端附近作振幅恒定的连续的简谐振动，就会有连续的横波波列沿弦线从
A 端向 B
端传播。我们称没有经过反射的波为前进波。当一列前进波行进到固定端 B
时，便发生反射，沿着前进波的反方向传播；当遇到 A
端时，发生第二次反射；继而又沿着前进波的方向传播再到达固定端
B，发生第三次反射\...\...我们称经过一次或多次反射的波为反射波。由于源振动是连续的，所以在弦线上既有前进波，又有无数的反射波。一般情况下，由于这些波的相位不同，振幅很小，振动现象不显著。然而，如果弦线的长度和波长之间满足某种关系，使得当前进波和许多反射波都具有相同的相位时，弦线上各点都作振幅各自恒定的简谐振动。这时，弦线上有些点振动的振幅最大，称为波腹；而另外有些点的振幅为零，称为波节，形成驻波现象。

**2．具体推导**

相邻两波节/波腹间距为半波长，而弦线两端固定，即两端都是波节，则弦线长度$L$应为半波长整数倍

波长$\lambda$满足：

$$\lambda = \frac{2L}{n}\quad n = 1,2,3,\cdots$$

若振动频率为$f$，横波沿弦线传播速度为

$$v = \lambda f$$

根据波动理论，张力为$T$，线密度为$\mu$，则横波满足：

$$\frac{\partial^{2}y}{\partial t^{2}} = \frac{T\partial^{2}y}{\mu\partial x^{2}}$$

$$\frac{\partial^{2}y}{\partial t^{2}} = v^{2}\frac{\partial^{2}y}{\partial x^{2}}$$

式中 x为波在传播方向（与弦线平行）的位置坐标，y 为振动位移。

通过比较得到波的传播速度

$$v = \sqrt{T/\mu}$$

又由于$v = \lambda f，得$

$$\lambda = \frac{1}{f}\sqrt{T/\mu}$$

两边取对数

$$\log\lambda = \frac{1}{2}\log T - \frac{1}{2}\log\mu - \log f$$

根据公式，若固定f及μ，改变张力T，测出各相应波长λ，作log λ -log
T图，若得一直线，计算其斜率值，如为1/2，则证明了λ∝${T\ }^{1/2}$的关系成立。同理，固定线密度μ及T改变振动频率f，测出各相应波长λ，作
log λ -log f 图，如得到斜率为-1的直线则验证了λ∝${f\ }^{- 1}$。

弦线上的波长可利用驻波原理测量。当两个振幅和频率相同的相干波在同一直线上相向传播时，其所叠加而成的波称为驻波，一维驻波是波干涉中的一种特殊情形。在弦线上出现许多静止点，称为驻波的波节，相邻两波节间的距离为半个波长。

**声速测量实验**

**1．利用驻波法测声速**

（1）信号发生器输出频率为f的信号给超声发射换能器，发射换能器将电压信号转成超声波并发射。接收换能器接收超声波并转换成电压信号给示波器。

（2）由声波传输理论可知，如果接收面和发生面严格平行，即入射波在接收面上垂直反射，入射波和反射波相互干涉形成驻波。此时，两换能器之间的距离恰好等于其声波半波长的整数倍。在声驻波中，波腹处声压最小，波节处声压最大。接收换能器的反射界面处为波节，声压效果最大。所以，可以从接收换能器端面声压的变化来判断超声波是否形成驻波。

（3）转动鼓轮，改变两只换能器间的距离，在一系列特定的距离上，将会出现稳定的驻波，记录下出现最大电压数值时标尺上的刻度，相邻两次最大值对应的刻度值之差即为半波长。

（4）声波的频率$f$是一个已知的确定的数值，测出波长后，可以用公式：$v = \lambda f$来计算超声波的传播速度。

**2．利用相位法测定声速**

将发射波和接收波同时输入示波器，并且以 X-Y
模式显示，两波的频率相同，相位不同。当接收点和发射点的距离变化等于一个波长时，相位差正好是2π。

实验时，通过改变发射器和接收器之间的距离，观察相位的变化，当相位改变π，相应距离的改变量即为半波长，又声波的频率$f$已知，根据公式$v = \lambda f$求出波速。

**3．声速的理论值**

利用声速在空气中的理论公式可以计算空气中声速的理论值：

$$v = v_{0}\sqrt{\frac{T}{T_{0}}} = v_{0}\sqrt{1 + \frac{t}{273.15}}$$

其中$T = (t + 273.15)K$，$v_{0} = 331.45m \cdot s^{- 1}$，是$0{^\circ}C$时的声速，$t$为摄氏温度。

6.  **实验总结与思考**

**思考题**

**1. 调节振动源上的振动频率和振幅大小后对弦线振动会产生什么影响？**

（1）调节振动源的频率就是改变弦线驱动力的频率，也就是弦线振动频率改变。而且当振动源频率达到弦线基频的整数倍时，弦线会发生共振，振幅特别大，且会形成稳定驻波。

（2）调节振动源的振幅大小相当于改变驱动力大小，改变输入的能量多少。频率一定的情况下，振动源振幅越大，弦线振幅也越大，更利于观察。

**2. 如何来确定弦线上的波节点位置？**

首先要调节弦线达到共振，即振幅最大的情况，此时弦线上才有稳定驻波，出现波节。通过观察，弦线上振幅最小或是完全不振动的点就是波节。肉眼观测看来，波节处弦线清晰、不动，其他位置弦线振动、模糊。波节不明显时可以根据弦线长度与波长计算波节位置。

**3.
在弦线上出现驻波的条件是什么？在实验中为什么要把弦线的振动调到驻波现在最稳定、最显著的状态？**

（1）出现驻波的条件:

(A)振动源的频率是弦线基频的整数倍，达到共振

(B)或者弦线的有效长度是半波长的整数倍，即：

$$L = n\frac{\lambda}{2}，n = 1,2,3\ldots\ldots$$

（2）把弦线的振动调到驻波现在最稳定、最显著的状态，即调到共振。此时振幅最大，现象最明显，驻波现象更容易观测到，也就可以使肉眼观测的误差减小，实验结果更精确。

**4.
在弹奏弦线乐器时，发出声音的音调与弦线的长度、粗细、松紧程度有什么关系？为什么？**

公式：

$$f = \frac{1}{\lambda}\sqrt{\frac{T}{\mu}} = \frac{2}{\lambda}\sqrt{\frac{T}{\pi\rho d^{2}}}$$

由公式可知：

弦线有效长度越短，音调越高。有效长度越长，音调越低（有效长度即对应波长）

弦线越细，音调越高。弦线越粗，音调越低。

弦线越紧，音调越高。弦线越松，音调越低。

**5.
若样品弦线与装置上的弦线直径略有差别，请判断是否需要修正，如何进行？**

需要修正。

线密度$\mu = \rho\pi\frac{d^{2}}{4}$

使用螺旋测微器分别测量样品弦线与装置上弦线的直径，通过公式和样本弦线的直径、线密度算出弦线体密度ρ，之后将弦线体密度ρ与装置上弦线直径d代入公式，计算得出装置弦线的线密度。不过注意测量时样品与装置上弦线最好都处于紧绷状态，减少误差。

**6.
对于某一共振频率，增大或减少频率的调节过程中，振幅最大的频率位置往往不同，如何解释这一现象？**

（1）仪器本身的问题，信号发生器的频率输出经常会发生突变，很难得到一个准确的读数。

（2）由于弦线的振动，导致张力架不再水平。事实上实验过程中我发现张力架实在是难以保持水平，刚刚调完平，振动一会就歪了，再调整还没等读数稳定就又歪了。

**心得体会**

（1）做实验不要犯强迫症，追求完美固然好，但过于认真也会导致效率低下。本次实验时我有一段时间一直在纠结调平的事情，做一会实验调一下平，但是由于调平时的干扰，数据就会变动，需要等待它稳定，而往往读数还没稳定，张力架就由于弦线的振动又歪了，实在是折磨，导致我浪费了很多时间，实在是不应该，事实上这是仪器的问题，基本是难以靠人为操作解决的，我不应该浪费这么多时间的。最后拖到了六点多才做完实在是不应该。

（2）要善于发现，多思考，比如发现驻波法比较难以判断峰值，就要思考背后原因，一方面峰值附近变化率本来就小，另外一方面仪器精度有限。

（3）遇到困难不要害怕，及时问老师同学。这次实验一开始在找共振频率时我试了半个多小时没找到，当时心态崩了，自己不好意思问老师，一直卡在那里，浪费了大量时间。最后问老师一下子就明白了，原来频率之间有着倍数关系，瞬间就快起来了。有时候问老师能够大大提高效率，而且也能加深自己对于实验的理解。

（4）与同学间要互相帮助，比如弦线密度与频率关系实验就需要同学们之间数据共享。

（5）要认真对待误差，仔细分析误差产生原因，才能让自己的实验技术不断提升。比如在发现频率与弦线密度实验结果与理论值区别极大，就要思考其背后的原因，是大家砝码差别较大，变量没有控制好，下次就可以吸取教训。

（6）要重视预习工作，理解了原理之后做实验的效率和对知识的理解都会大大提升。实验和原理是可以互相裨益的，通过预习了解原理，指导实验；通过实验进一步加深对原理的理解和对知识的掌握。本次实验我就吃了预习不到位的亏，虽然原理都看了，但是没有发现频率的倍数关系，导致浪费大量时间。

（7）灵活使用计算机软件对于处理实验数据非常重要。这次实验的绘图、数据拟合、许多计算我都是用Excel完成的，大大节约了我的时间精力。

（8）要注意细节，比如本次实验就有很多小的细节，如频率的倍数关系，调节水平、弦线两端为波节等。
